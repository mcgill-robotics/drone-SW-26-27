## General Info About DSM and DTM
ODM supports both DSM and DTM generation, but they are not generated by default. ODM uses a Simple Morphological Filter (SMRF) to classify ground points when generating a DTM. Both DSM and DTM map out the elevation. However, DSM also records the height of the surfaces like building roofs and trees, whereas DTM only estimates the bare ground underneath those objects. DSM does not require SMRF to remove the above ground objects, and it is only used for DTM to generate ground points.
Source: https://docs.opendronemap.org/tutorials

A DSM can be generated through the .create_task() function by passing in the dsm property set to true in an object like such
```
task = node.create_task(images, {
    "dsm": True
})

task.wait_for_completion()
task.download_assets("results")
```
Additionally, the .create_task() function generates an orthophoto by default (no additional options required).

For reference, the structure of the create_task() function is:
```
create_task(files, options={}, name=None, progress_callback=None, skip_post_processing=False, webhook=None, outputs=[], parallel_uploads=10, max_retries=5, retry_timeout=5)
```
Source: 
https://pyodm.readthedocs.io/en/stable


## Useful Options
| Option | Usage | Default value |
|---|---|---|
| `dsm` | Make surface height map | `false` |
| `dtm` | Make ground terrain map | `false` |
| `dem-resolution` | Height map resolution in cm/pixel | `5` |
| `dem-gapfill-steps` | Controls how much ODM tries to fill in missing elevation data in the height map (without gapfill, there might be holes with no data in the map) | `3` |
| `dem-decimation` | Reduce point count for faster DEM generation | `1` |

Source: https://docs.opendronemap.org/arguments/dem-gapfill-steps/

## General Flow of DSM Map Generation
- **Intake collection of photographs**
- **ODM uses OpenSfM (Structure from Motion):**
  - **Feature detection:** Finds recognizable points in each photograph.
  - **Feature matching:** Identifies corresponding points between pairs of photographs.
  - **Feature tracks:** Groups matching observations across multiple photographs. (A track is a set of feature points from different images that have been recognized to correspond to the same physical point.)
  - **3D reconstruction:** Uses those tracks to estimate the 3D positions of the points and the camera positions.
  - **Output:** Sparse 3D point cloud and estimated camera positions.
- **ODM uses OpenMVS (Multi-View Stereo):**
  - Generates dense 3D point clouds, containing many more 3D points than the previous sparse reconstruction.
- **ODM DSM generation:**
  - Uses the dense 3D point cloud to estimate surface elevations.
  - Converts the surface elevations into a 2D raster grid.
  - Each pixel stores an elevation value.
  - Outputs `dsm.tif`.

DSM map info (sources: https://github.com/OpenSfM/OpenSfM, https://opensfm.org/docs/using.html, https://github.com/cdcseacave/openMVS/blob/develop/docs/wiki/Interface.md)
